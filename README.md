### Why AGPL?

This project was originally created to help my daughter develop confidence and fluency in mathematics.

You are welcome to use, study, modify, and share this software.

The AGPL was chosen to ensure that improvements remain available to the community. If you deploy a modified version of this software, the corresponding source code must also be made available under the same license.

The goal is to encourage collaboration and keep educational software accessible to students, parents, and educators.
