# MathFacts
MathFacts is an educational application designed to help children build confidence and fluency with basic math facts through practice, immediate feedback, and positive reinforcement.

The application rewards effort, progress, and achievement while identifying areas where additional practice is needed. It is intended to support parents, educators, and children by making regular math practice engaging and measurable.

## MVP
The initial MVP is a client-side Angular application focused on practicing addition and subtraction facts.

Features include:

- Mixed addition and subtraction problem generation
- Configurable difficulty levels (0-20, 0-100, etc.)
- Tracking of correct and incorrect answers
- Response time measurement for each question
- End-of-session performance summaries
